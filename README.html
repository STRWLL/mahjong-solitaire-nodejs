麻雀ソリティア

必要なもの

nodejs version 24

役一覧確認

ターミナルでこのディレクトリを開き、以下。
node list-patterns.js

点数計算

(1) 翻数合計 n による点数
(1-1) n <= 4
500 × (2 の n 乗) の上2桁までの丸め
(1-2) n > 4
8000 × (2 の 3 乗根 の (n - 4) 乗) の上2桁までの丸め
(10 翻で役満相当となる)
(2) 役満数合計 m による点数
32000 × m
(1) + (2)

ゲーム開始

ターミナルでこのディレクトリを開き、以下。
node index.js

ゲーム中の操作

  • 左キーでカーソルを左に動かす
  • 右キーでカーソルを右に動かす
  • エンターキーで決定する

表記

表示の都合上、牌は半角3文字で表現される。
実際には色付き
  • $n$ 萬子
  • *n* 筒子
  • !n! 索子
  • TON 東
  • NAN 南
  • XIA 西
  • PEI 北
  • [ ] 白
  • [#] 發
  • [@] 中
また、ゲーム中の操作選択肢も同様に半角3文字で表記される
  • KAN [ ] 白をカンする
  • FIN あがる
